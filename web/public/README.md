## ロゴ差し替え方法

このフォルダ内の以下ファイルは、ブランドロゴの **暫定 SVG（近似版）** です。
本物のロゴを差し替えるときは、同名で同フォーマット（SVG 推奨）のファイルで上書きしてください。

| ファイル | 用途 |
|---|---|
| `logo.svg` | フルロゴ（モノグラム + ワードマーク + サブタイトル）。フッタ・ランディングで使用。 |
| `logo-mark.svg` | モノグラム（Sマーク）のみ。ヘッダで使用。 |

### SVG の場合の制約

- `viewBox` は外側の `width` / `height` に依存しないため、サイズ調整は表示側で行えます。
- 線色は `currentColor` で外側から制御しているので、ヘッダの light / dark モードでも自動追従します。
  もし固定色のロゴ画像を入れる場合は、`logo-light.svg`（白用）と `logo.svg`（黒用）の 2 種類を用意してください。

### PNG / JPG を入れる場合

透過 PNG を入れる場合は `logo.png` / `logo-mark.png` として配置し、各 `<img src="...">`
の参照を `.svg` → `.png` に書き換えてください（`SiteHeader.tsx`, `SiteFooter.tsx`,
`/index.html`）。
